# PGA TOUR

Een Nederlandstalige, responsieve fanpagina over de PGA TOUR, gemaakt met gewone HTML, CSS en JavaScript.

## Starten

Open `index.html` direct in een browser. Er is geen installatie of ontwikkelserver nodig. De golfbaanfoto's laden vanaf Unsplash; zonder internetverbinding blijft de pagina bruikbaar met de achtergrondkleur.

## Wat erin zit

- Toernooienfilter voor majors en signature events
- Klikbare toernooienkaarten met een korte uitleg
- Wisselbare profielen van Scottie Scheffler, Rory McIlroy en Xander Schauffele
- Mobiel navigatiemenu en uitleg van het toernooiformat

De pagina is onafhankelijk en bevat geen live scores of actuele ranglijsten. Raadpleeg de officiële PGA TOUR-site voor actuele speeldata en uitslagen.
